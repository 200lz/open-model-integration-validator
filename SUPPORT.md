# Support

Use GitHub Issues for reproducible bugs and narrowly scoped feature requests after
the repository becomes public. Search existing issues first and provide synthetic,
privacy-safe evidence. Do not disclose vulnerabilities or sensitive material in an
issue; follow [SECURITY.md](SECURITY.md).

OMIV is a pre-1.0 public preview. Community support is best effort: no response time,
resolution time, compatibility window, commercial support, or service-level agreement
is promised. This repository does not provide a hosted service, private connector,
enterprise dashboard, deployment admission service, or managed monitoring.
