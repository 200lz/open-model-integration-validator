# Governance

OMIV is currently maintainer-led. The maintainer reviews changes, protects canonical
evidence semantics, manages releases, and may reject changes that blur declarations,
observations, identity, authority, or policy results.

Public design discussion should occur in issues and pull requests. Material schema
changes require explicit rationale, compatibility impact, deterministic examples,
and offline verification tests. Security reports use the private process in
[SECURITY.md](SECURITY.md).

Releases require a version decision, changelog review, full validation, package and
license audits, and separate authorization for tagging or publication. Historical
unsigned tags remain unchanged and are classified
`LEGACY_UNSIGNED_TAGS_ACCEPTED_WITH_LIMITATION`; future releases may use signed tags
according to [docs/releasing.md](docs/releasing.md).

No standards-body status, certification authority, provider endorsement, foundation
membership, or registered trademark is claimed.
